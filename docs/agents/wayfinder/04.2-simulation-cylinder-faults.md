# [wayfinder:task] Simulation: Phase 3 (Cylinder Specific Faults & Windmilling)

## Problem Statement

To properly support generating datasets that accurately reflect historical catastrophic failures (like the Djibouti MQ-1B accident), the core engine model needs higher fidelity at the individual cylinder level and handling for catastrophic engine seizure dynamics. Currently, the engine outputs a single global EGT, and faults are broadly applied to the entire engine block.

## Solution

We will update the core simulation to output individual Exhaust Gas Temperatures (`egt_1` through `egt_4`) that mirror the baseline EGT but can be independently manipulated by faults. We will also introduce a specific `cylinder_failure` fault that sharply degrades a targeted cylinder, and support RPM coast-down to a windmilling state during total seizure.

## User Stories

1. As an ML Engineer, I want the `get_state()` telemetry to include `egt_1`, `egt_2`, `egt_3`, and `egt_4`, so that my models can detect localized cylinder anomalies rather than just global overheating.
2. As a Tester, I want to inject a `cylinder_failure` fault that specifies a target cylinder, so that I can recreate specific physical failures where a single cylinder's EGT plummets.
3. As a Tester, I want the `cylinder_failure` fault to also degrade overall engine performance (RPM drop) proportionally, so that the simulation physics remain somewhat realistic.
4. As a Data Scientist, I want the simulation to support a windmilling state where an incapacitated engine coasts down to a minimum RPM (e.g., 1000) rather than coming to a dead stop, to reflect realistic in-flight aerodynamics.

## Implementation Decisions

- **Cylinder Telemetry:** The `egt_1` to `egt_4` telemetry outputs have already been added to the base `engine.py`. They currently track the global filtered `egt` value plus independent sensor noise.
- **New Fault Type:** Implement `cylinder_failure` in the `FaultManager`. It should accept a parameter (e.g., `cylinder=3`) and apply a severe negative `output_offset` exclusively to that cylinder's EGT. It should also apply a negative `target_offset` to `rpm` based on severity.
- **Windmilling Simulation:** Rather than complex aerodynamic modeling, we will rely on injecting `sensor_drift` on `rpm` to force the RPM to a windmilling speed (1000 RPM) when the throttle is at 0 and the engine has seized.

## Testing Decisions

- **What makes a good test:** Tests should ensure that individual cylinders can deviate significantly from the baseline EGT while the others remain unaffected.
- **Tested Modules:** `Simulation` class, `FaultManager`
- **Test Scenarios:**
  - *Healthy Cylinders:* Ensure all 4 cylinders track within standard noise bounds of the global EGT.
  - *Cylinder Failure:* Inject `cylinder_failure` on cylinder 3. Assert that `egt_3` drops dramatically while `egt_1`, `egt_2`, and `egt_4` remain steady, and overall RPM drops.

## Out of Scope

- Thermodynamic modeling of heat transfer between adjacent cylinders.
- True aerodynamic windmilling calculations based on airspeed (we will use fixed RPM overrides).
