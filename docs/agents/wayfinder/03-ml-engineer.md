# [wayfinder:task] ML Engineer: Diagnostics & RUL Models (Stage 1 Baseline & Anomaly Detection)

## Problem Statement

The synthetic telemetry generator has successfully created 500 varied missions representing healthy and faulty UAV aero-piston engine operations. We need a machine learning pipeline to consume this data and train a baseline diagnostic model. Training directly on raw telemetry is suboptimal; the architecture dictates that the AI must learn from the residuals (Actual vs Expected) generated by a physics-based Digital Twin. Furthermore, point-in-time predictions lack temporal context, and supervised models alone cannot identify novel or unseen faults. We need an automated pipeline to compute residuals, engineer temporal features (rolling statistics), train a multi-class XGBoost classifier for known faults, and train an unsupervised Isolation Forest for open-set anomaly detection.

## Solution

Create a new `ml_pipeline` directory containing four main components:
1. **Residual Generator:** A script that loads the raw datasets, uses the thermodynamic maps from `simulation/engine.py` to calculate expected engine states, and computes `Actual - Expected` residuals.
2. **Feature Engineering:** A data transformation module that applies sliding windows to the residuals and raw telemetry to extract rolling statistical features (mean, variance, min, max) capturing temporal degradation trends.
3. **Supervised XGBoost Classifier:** A training script that consumes these engineered features, splits data strictly by mission, and trains an XGBoost model to accurately classify known discrete faults.
4. **Unsupervised Isolation Forest:** A training script that fits an Isolation Forest on the mixed engineered dataset (healthy + known faults) to act as a broad safety net for extreme out-of-distribution behaviors.

## User Stories

1. As an ML Engineer, I want a script to calculate Digital Twin residuals for the entire dataset offline, so that I can rapidly iterate on model training without waiting for physics simulations.
2. As an ML Engineer, I want to calculate rolling statistical features over fixed time windows (e.g., 10s, 30s), so that the ML models can interpret temporal degradation trends.
3. As an ML Engineer, I want to train an XGBoost multi-class classifier as the Stage 1 baseline, so that I have a fast, interpretable benchmark for known faults.
4. As an ML Engineer, I want the train/test split to group data strictly by mission files, so that time-series data leakage is prevented.
5. As an Operator, I want the system to flag extreme or unseen faults, so that out-of-distribution anomalies are caught even if the XGBoost classifier misclassifies them.
6. As an ML Engineer, I want to train an Isolation Forest on the full dataset, so that it can act as this unsupervised safety net for open-set anomalies.

## Implementation Decisions

- The pipeline will reside in a new `ml_pipeline/` module.
- `compute_residuals.py` (Ticket 01) iterates over parquet files, applies physics models to compute expected states and residuals, saving the output.
- `feature_engineering.py` (Ticket 02) consumes the residual data and computes rolling statistics, outputting ML-ready engineered datasets.
- `train_xgboost.py` (Ticket 03) loads engineered data, performs mission-based `GroupShuffleSplit`, and trains the XGBoost classifier on known targets.
- `train_isolation_forest.py` (Ticket 04) trains an Isolation Forest on the mixed dataset to output anomaly scores.

## Testing Decisions

- **Residual Computation Seam:** Test `compute_residuals.py` via CLI; verify healthy deterministic runs produce ~0.0 residuals (accounting for noise).
- **Feature Engineering Seam:** Test the rolling window math against a mocked DataFrame with a known, predictable trend.
- **XGBoost Training Seam:** Run the full training loop on a tiny toy dataset to assert the model can overfit and learn a basic fault signature, outputting class probabilities.
- **Isolation Forest Seam:** Test the training loop on a toy dataset and assert that it successfully flags an artificially injected extreme outlier outside the training distribution.
