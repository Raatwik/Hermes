# [wayfinder:doc] ML Pipeline Execution Guide

## Overview
This document serves as a quick-start reference for executing the ML training pipeline. The Python code for the models is already fully implemented in the `ml_pipeline/` directory. No dedicated spec file or complex configuration is required to begin training.

## Execution Sequence

To train the models from scratch using the 4.3 GB generated Parquet dataset in `data/`, run these scripts in order from the root directory:

### 1. Data Preparation (5 - 15 minutes)
These scripts utilize multiprocessing to process the dataset rapidly across CPU cores.
```bash
# Computes the Digital Twin residuals (Actual - Expected)
python ml_pipeline/compute_residuals.py

# Extracts rolling statistical features and sliding windows
python ml_pipeline/feature_engineering.py
```

### 2. Stage 1 Models: Diagnostics (< 5 minutes)
Trains the baseline anomaly detection and discrete classification models.
```bash
python ml_pipeline/train_xgboost.py
python ml_pipeline/train_isolation_forest.py
```

### 3. Stage 2 Models: Prognostics (15 mins - 2 hours)
Trains the Probabilistic LSTM to forecast Remaining Useful Life (RUL).
```bash
python ml_pipeline/train_lstm_rul.py
```
*Note: This script will take ~15-45 minutes on a CUDA GPU, or a few hours if constrained to the CPU.*

## Configuration & Specs
The scripts are built to run out-of-the-box and do not require a `.yaml` or `.json` spec file. They rely on standard `argparse` defaults:
- **Epochs**: 50
- **Batch Size**: 32
- **Learning Rate**: 1e-3
- **Patience**: 10 (Early stopping)

You can override these via terminal flags if needed (e.g., `python ml_pipeline/train_lstm_rul.py --epochs 100`).

## ⚠️ Critical Resource Warning (RAM)
The `TelemetryDataset` loads the Parquet files into memory to create sliding windows. Attempting to load the entire 4.3 GB dataset at once on a standard local machine may cause an **Out of Memory (OOM) crash**. 

**Workaround:** 
If your system runs out of RAM, move a subset of the parquet files (e.g., 20-30 files) into a temporary folder (like `data_subset/`) and point the scripts to it using the `--data_dir` flag:
```bash
python ml_pipeline/train_lstm_rul.py --data_dir data_subset
```
